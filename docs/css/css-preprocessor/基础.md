# vue2+webpack+scss 设置全局变量文件

yarn add style-resources-loader vue-cli-plugin-style-resources-loader -D

在 vue.config.js

```
module.exports = {
  pluginOptions: {
    "style-resources-loader": {
      preProcessor: "scss",
      patterns: [
        path.resolve(__dirname, "./src/assets/custom/__variable.scss") // 这里填写你的 SCSS 变量文件路径
      ]
    }
  }
}
```
